Translations

Show your S0tool in your own language. Pick a language file, add one line to Home Assistant and every sensor gets a name you can read. Nothing is re-flashed and nothing breaks.

How it works

The S0tool entities are named in Dutch by default, for example Actuele energie and Totaal opgebracht. The translation files change only the displayed name (friendly_name) in Home Assistant. The entity IDs stay the same.

Safe to use: your dashboards, utility meters, templates and the Energy dashboard keep working, because they use the entity IDs. The firmware is not touched, so you do not need to update or re-flash your S0tool.

Quick start

  1. Download the translations and copy the s0tool_translations folder to your Home Assistant config/ folder.
  2. Add one language to your configuration.yaml:
homeassistant:
  customize: !include s0tool_translations/s0tool_eng.yaml
  1. Restart Home Assistant, or run Developer tools → YAML → Reload customizations.

To switch language, use another file name. To go back to Dutch, remove the lines.

Each file translates the same 49 entities: the ESPHome sensors, the version sensors, the template sensors and the utility meters.

Good to know

  • Only what you see in Home Assistant changes. The ESPHome web interface of the device (port 80) keeps its names.
  • Use one language file at a time. Already have a customize file? Copy the entries you want into it.
  • Entities that contain your device name in the ID (... online sinds, ... IP-adres, ... Mac-adres) are included as commented examples at the bottom of each file. Adjust them to your device name.
  • Some views in newer Home Assistant versions, such as the device page, show the entity's own name instead of friendly_name. Rename the entity under Settings → Entities in that case.

Add your language

Missing your language, or want a better translation? It is a small, friendly contribution:

  1. Copy s0tool_eng.yaml to s0tool_<code>.yaml, for example s0tool_es.yaml.
  2. Translate the friendly_name values. Do not change the entity IDs (the lines ending in :) or the icon lines.
  3. Keep the first line in this format: # S0tool - Español (es).
  4. Send a pull request. GitHub checks your file automatically and tells you what to fix.

That is all: this page and the download update themselves on the next site build.
