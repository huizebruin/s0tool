CI/CD Pipeline

S0tool uses GitHub Actions to automate firmware builds, testing, and deployment. Every push triggers a complete pipeline that compiles all device configurations.

Overview

The S0tool CI/CD pipeline automatically:

  • Compiles ESPHome firmware for all device configurations
  • Tests changes on every pull request
  • Deploys updates to GitHub Pages
  • Creates releases with compiled binaries
  • Maintains consistency across devices

Workflow Triggers

The pipeline starts automatically on:

  • Push to main - Compiles and deploys
  • Pull requests - Tests changes before merge
  • Releases - Creates release builds
  • Manual dispatch - On-demand builds

Pipeline Stages

Stage 1: Build Firmware 🏗️

ESPHome compiles all device configurations using the official ESPHome workflow.

  • Runs on Ubuntu Latest
  • ESPHome Version: 2026.8.0
  • Compiles 11 device configurations
  • Generates binary artifacts

Stage 2: Consolidate Artifacts 📦

Downloads and organizes all compiled binaries into a clean folder structure.

  • Merges artifacts from parallel builds
  • Removes intermediate version folders
  • Copies static website files
  • Prepares output for deployment

Stage 3: Deploy to GitHub Pages 🚀

Deploys the complete site with firmware to GitHub Pages.

  • Only runs on main branch pushes
  • Uploads to GitHub Pages environment
  • Makes firmware available instantly
  • Public URL: https://s0tool.nl

Deployment

What Gets Deployed

  • Static website (HTML, CSS, JS)
  • Firmware binaries for all devices
  • Installation tools
  • Web-based flashing interface

Deployment Permissions

  • pages:write - Write to GitHub Pages
  • id-token:write - Generate auth tokens
  • contents:read - Read repository

Files Copied During Deployment

  • Everything from static/ folder
  • All compiled firmware binaries
  • Organized by device name
